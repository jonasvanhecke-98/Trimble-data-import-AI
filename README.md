# Trimble Data Import AI — clean restart

1. Upload deze bestanden rechtstreeks in de ROOT van je GitHub repo.
2. GitHub Settings -> Pages:
   Source = Deploy from a branch
   Branch = main
   Folder = /(root)
3. Gebruik in Trimble Add Custom deze CORS-veilige manifest URL:
   https://cdn.jsdelivr.net/gh/jonasvanhecke-98/Trimble-data-import-AI@main/manifest.json
4. De extension zelf draait op:
   https://jonasvanhecke-98.github.io/Trimble-data-import-AI/

Deze versie gebruikt bewust geen React, Vite, GitHub Actions of subroutes.
